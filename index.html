CONNECTION GUIDE & SECURITY NOTES

The API endpoint must be deployed as a Web App. The GitHub frontend needs access to the endpoint. Because this Apps Script API currently uses JSONP, the app password is sent in request URLs; use a strong unique password and do not share browser history or endpoint logs.
